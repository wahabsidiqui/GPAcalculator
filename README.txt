GPA Calculator (Kotlin + Jetpack Compose)

1. Unzip, then in Android Studio: File > Open > select the GpaCalculator folder.
2. Wait for Gradle sync to finish (needs internet the first time).
   If Studio offers to upgrade the Android Gradle Plugin, you can accept or ignore it.
3. Pick an emulator or plug in a phone (USB debugging on) and press Run.

Edit the grade scale in app/src/main/java/com/example/gpacalculator/GpaViewModel.kt (gradePoints).
